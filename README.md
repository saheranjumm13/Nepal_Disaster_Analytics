# Nepal Disaster Analytics Dashboard

## 📊 About the Project

An interactive **Power BI dashboard** for analyzing disaster incidents and their impact across Nepal.

The dashboard provides insights into:

- Disaster Incidents
- Deaths
- Injuries
- Missing People
- Houses Destroyed
- Houses Affected
- Infrastructure Damage
- Economic Loss
- District-wise Analysis
- Province-wise Analysis
- Disaster Trends
- Disaster Severity

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel

## 📌 Dashboard Pages

### 1. Nepal Disaster Overview
Provides an overall summary of disaster incidents and key statistics.

### 2. District & Province Analysis
Shows disaster impact across different districts and provinces.

### 3. Disaster Trend Analysis
Shows disaster trends over time.

### 4. Infrastructure & Severity
Shows infrastructure damage, economic loss, and disaster severity.

## 📂 Project Files

- **Power BI** – Power BI dashboard file
- **Dataset** – Dataset used for analysis
- **Screenshots** – Dashboard screenshots

## 🚀 How to Use

1. Download the `.pbix` file.
2. Open it using **Power BI Desktop**.
3. Refresh the data if required.
4. Use the filters and visuals to explore the dashboard.
